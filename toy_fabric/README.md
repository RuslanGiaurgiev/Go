**Задача: "Фабрика игрушек с конвейером"**

**Условие:**
Создайте фабрику по производству игрушек с конвейерной линией.

**Детали:**
- **3 рабочих** (горутины) собирают игрушки
- **2 упаковщика** (горутины) упаковывают игрушки  
- **1 контролёр качества** (горутина) проверяет игрушки
- **Конвейер** (буферизованный канал) вмещает 5 игрушек

**Процесс:**
1. **Рабочий** собирает 1 игрушку за 1 секунду
2. **Контролёр** проверяет игрушку за 0.5 секунды (90% проходят)
3. **Упаковщик** упаковывает игрушку за 1.5 секунды

**Требования:**
- Каждая игрушка имеет уникальный ID
- Считать отдельно: произведено, прошло контроль, упаковано
- Работать 30 секунд
- Вывести детальную статистику

**Усложнение:**
- Если игрушка не прошла контроль, она возвращается на доработку
- Бракованные игрушки идут в начало конвейера
