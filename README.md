# Мои проекты на Go

Этот репозиторий содержит мои работы и эксперименты с языком программирования Go.

## 📁 Структура проекта

### 🎯 Основные файлы

- **`main.go`** - Главный файл приложения с базовым взаимодействием с пользователем
- **`go.mod`** - Файл модуля Go с описанием зависимостей

### 📂 Папка `tasks/`

Содержит различные учебные задания и эксперименты с Go:

- **`les1/main.go`** - максимально примитивный синтаксис  
  *Пример: просто вывод суммы двух чисел*

- **`les2/main.go`** - так же самое начало пути в go
  *Пример: вывод нескольких переменных, а после изменение переменных (На слова не обращаем внимание :). )*

  - **`les3/main.go`** - задачаки от нейросети самого базового уровня
  *Пример: начальные базовый функции*

  - **`les4/main.go`** - первый билд файлы
  *Пример: просто создание exe файла, который открывается на другом пк (На слова так же не обращаем внимание :).*

  - **`les5/main.go`** - начальные работы с пакетами и структурами
  *Пример: вывод структуры которая находится в другом пакете*

  - **`les6/main.go`** - первые работы с интерфейсами
  *Пример: вывод сохраненных данных и использование интерфейса для более адекватного и красивого кода*

  - **`test1/main.go`** - грубо говоря те же задачаки от нейросети самого базового уровня
  *Пример: начальные функции*

  - **`test2/main.go`** - тесты со структурами
  *Пример: работа со структурами**

  - **`test3/main.go`** - начальные задачки с массивами
  *Пример: базовые работы с массивами*

## 🛠 Технологии

- **Go (Golang)** - основной язык разработки
- **Стандартная библиотека Go** - используются встроенные пакеты
